# Analyse SQL et construction de KPI

**SQL · jointures · agrégations · KPI**

## Contexte

Les données opérationnelles doivent être transformées en indicateurs directement utilisables par les équipes métier.

## Problématique

Comment traduire une question métier en requêtes SQL fiables et vérifiables ?

## Démarche

- identification des tables pertinentes ;
- analyse des clés ;
- jointures ;
- agrégations ;
- contrôles de cohérence ;
- construction des KPI.

## Résultats

Les requêtes produisent des indicateurs reproductibles et permettent de remonter de l'indicateur agrégé jusqu'aux données sources.
