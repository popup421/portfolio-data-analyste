# Data Quality et détection d'anomalies

**Python · SQL · Data Quality**

## Contexte

Les problèmes de qualité des données peuvent provenir de valeurs manquantes, doublons, incohérences entre colonnes ou ruptures de règles métier.

## Problématique

Comment identifier automatiquement les anomalies avant qu'elles ne se propagent dans les analyses ou les systèmes aval ?

## Démarche

- définition de règles de qualité ;
- contrôle des valeurs nulles et doublons ;
- contrôle des domaines de valeurs ;
- contrôles de cohérence entre colonnes ;
- détection des valeurs atypiques ;
- production d'un rapport d'anomalies.

## Résultats

Le projet transforme les contrôles de qualité en indicateurs exploitables : nombre d'erreurs, taux de conformité et répartition des anomalies.
