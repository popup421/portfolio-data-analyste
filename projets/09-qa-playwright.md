# QA Data / tests automatisés avec Playwright

**Python · Playwright · tests fonctionnels**

## Contexte

La qualité d'une application ne dépend pas uniquement de la qualité du code : les parcours utilisateurs doivent également être vérifiés.

## Problématique

Comment automatiser un scénario utilisateur représentatif et détecter une régression ?

## Scénario

```text
Ouverture du site
      ↓
Navigation
      ↓
Saisie
      ↓
Action utilisateur
      ↓
Vérification du résultat
```

## Démarche

- définition du scénario ;
- sélection des assertions ;
- automatisation avec Playwright ;
- exécution ;
- analyse des échecs.

## Résultats

Le test transforme un parcours manuel en contrôle reproductible.

`Python` `Playwright` `tests fonctionnels` `QA`
