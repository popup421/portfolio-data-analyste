# Application interactive Data / IA

**Streamlit · Python · pandas · Plotly**

## Contexte

Une analyse peut être plus facilement exploitée lorsqu'elle est accessible via une interface interactive.

## Problématique

Comment transformer une analyse Python en application permettant à un utilisateur d'explorer les données sans manipuler directement le code ?

## Fonctionnalités

- chargement des données ;
- exploration ;
- nettoyage ;
- indicateurs ;
- visualisations interactives ;
- présentation des résultats.

## Architecture

```text
Données → Python/pandas → Analyse → Plotly → Streamlit
```

## Résultats

L'application fournit une interface simple pour explorer les données et présenter les résultats analytiques.
