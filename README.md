# Portfolio Data Analyst

Portfolio professionnel en Markdown, compatible avec GitHub Pages.

## Publication

1. Créer un dépôt GitHub, par exemple `portfolio-data-analyste`.
2. Copier le contenu de ce dossier dans le dépôt.
3. Dans **Settings → Pages**, sélectionner le déploiement depuis la branche principale.
4. Le site sera accessible via l'URL GitHub Pages du dépôt.

## À personnaliser

- nom et coordonnées ;
- URL GitHub ;
- URL LinkedIn ;
- liens vers les dépôts des projets ;
- captures d'écran dans `images/` ;
- résultats chiffrés de chaque projet ;
- intitulés exacts des projets.
